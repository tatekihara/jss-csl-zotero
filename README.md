# 社会学評論スタイル CSL（Zotero 用・非公式 / unofficial）

> **このZotero用のcslスタイルは、日本社会学会が公式に提供または承認したものではありません。**
> 『社会学評論スタイルガイド』第3版を参照して木原盾/Tate KIHARA（慶應義塾大学）が湘南藤沢キャンパスでの教育目的に作成した非公式のスタイルで、CC BY-SA 3.0ライセンスに従い公開しているものです。他の方の利用は妨げませんが、各自の責任で使ってください。

`jss-styleguide3-zotero.csl` は、『社会学評論スタイルガイド』第3版にできるかぎり準拠した Zotero 用の引用スタイルです（Zotero 9 で動作確認済み）。和文文献と英語文献が混在する文献リストを、「言語」欄の値に応じて書式を切り替えて出力します。英語以外の外国語文献には未対応で、英語向けの書式（and 連結、タイトルの大文字化など）が適用されます。

想定している主な利用者は、木原研究会（ゼミ）で卒業プロジェクトや修士論文を書く学生です。

**Zotero を使うのが初めての方へ**: 入力欄と出力結果を並べて説明した HTML の使い方ガイドを同梱しています（`jss-styleguide3-zotero-guide.html`）。ウェブ版は https://tatekihara.github.io/jss-csl-zotero/ です。この README は仕様の詳細と既知の制約をまとめたもので、はじめて使うときは使い方ガイドから読むことをお勧めします。

このZoteroのcslファイルは、木原盾/Tate KIHARA（慶應義塾大学）が、Kei SATO氏（京都大学）がCC BY-SA 3.0ライセンスのもとで公開しているJuris-M用スタイル「Juris-Mで社会学評論」（https://github.com/keisato0/jss-csl ）をフォークし、標準のZoteroで使えるように移植したものです。同スタイルは、Jonathan LEWIS氏（一橋大学）が作成したJuris-M用スタイル「日本社会学会 (author-date, Japanese)」をSATO氏が修正したもので、著者表示は両氏の連名になっています。和文と欧文で書式を切り替えるレイアウト構成は、LEWIS氏の原型から受け継いだ設計です。

本スタイルはβ版です。作成者は木原盾/Tate KIHARA です。詳しい注意事項と免責は末尾のクレジットを参照してください。

ライセンスはもとにしたスタイルと同じ CC BY-SA 3.0 です（継承義務があるため、改変版も同じライセンスで公開されます）。

## 最初に必ずお読みください

このスタイルには、知らないと文献リスト全体が崩れる前提が2つあります。細かな書式の注意はあとの節に譲りますが、この2つだけは必ず守ってください。

**1. 和文文献の「言語」欄に必ず `ja` と入れる。** このスタイルは言語欄が `ja` のとき和文書式に切り替わります。和文文献の言語欄が空だったり「日本語」と入っていたりすると、その文献はまるごと英語書式（カンマ区切り、書名イタリックなど）で出力され、文献リストが成立しません。Zotero が自動取得したアイテムは要注意です。英語文献は言語欄が空のままで構いません（英語書式が既定のため。`en` と入れても同じです）。

**2. 文献リストの並び順は、提出前に必ず自分で確認して手修正する。** 規定では和文文献も英語文献と一緒に著者のローマ字順で並べますが、Zotero は漢字の読みを知らないため、和文文献は文字コード順に並びます。これはスタイル側では解決できません。並び順の最終確認と手作業での並べ替えまでが、このスタイルの前提となる使い方です。

## インストール

Zotero の設定を開き、「引用」タブの「スタイル管理」にある「Add from File…」ボタンを押して、この .csl ファイルを選択してください。インストール時に検証の警告が出る場合がありますが、これは本スタイルが和文・欧文の書式切り替えのために CSL の拡張機能（複数レイアウト）を使っているためです。

Zotero はスタイルをファイル名ではなくスタイル固有の ID で識別します。同じ ID の新しい版を追加した場合は自動的に置き換わります。ID の異なる別のスタイルを以前に入れている場合は一覧に両方が残るので、古いほうは「スタイル管理」で選んで削除してください。

## Zotero への入力のしかた

このスタイルは、Zotero のアイテムが次のように入力されていることを前提とします。

1. **言語欄**: 和文文献には必ず `ja` と入力してください（`ja-JP` も可）。「日本語」のような語は無効です。この値が空だと英語書式で出力されるため、英語文献は空欄のままで構いません（`en`・`en-US` を入れても同じです）。
2. **訳書**: 訳書として登録し、「出版年月日」に訳書の出版年、作成者に「翻訳者名」の行を追加、原著の出版年を「Original Date」欄に入れてください（例: 1957）。原著者名はアルファベットのフルネームで入力してください（「訳書・翻訳論文」の節を参照）。「Original Date」欄が見当たらない古いバージョンの Zotero では、まず Zotero 本体を更新してください。
3. **再版・復刻版**: 「出版年月日」に手元の版の出版年、初版年を「Original Date」欄に入力してください（翻訳者名は入れません）。翻訳者の有無で訳書と再版を区別しています。
4. **和書の版表記**: 「新版」「第2版」などは、規定どおり奥付のまま「題名」欄に含めてください（書名のあとに半角スペースで併記する方式、規定23頁）。「版」欄に数字を入れた場合は、出版社名の前に「第2版」として出力されます。
5. **電子媒体で利用した文献**: 「アクセス日時」と URL を入力してください。（取得日，URL）が付くのは、ウェブページ・ブログを除き**「アクセス日時」を入力した文献だけ**です。紙媒体で利用した文献にはアクセス日時を入力しないでください（URL だけなら付きません）。ページ番号のある雑誌論文は既定では出力されません（項目7を参照）。雑誌論文を JSTOR などのデータベースで取得した場合は、URL の代わりに「アーカイブ」欄にデータベース名を入れると（取得日，データベース名）と出力されます。
6. **未公刊の学会報告**: 「学会発表」タイプを使い、学会名は「学会名」欄か「紀要名」欄のどちらかに入れてください。規定26頁の「報告者名，大会開催年，「報告のタイトル」第○回日本社会学会大会報告原稿．」の位置に出力されます。「紀要名」欄に入れた場合はそちらが優先されます（刊行された大会論文集の場合は、「紀要名」に論文集名を入れ、出版社・ページ・編者を入れると『論文集名』の形になります）。
7. **ページ番号のある雑誌論文の URL・取得日**: Zotero の既定では、ページ番号が入っている雑誌論文・新聞記事・雑誌記事の URL と取得日は、引用処理に渡る前に削除されます。規定4.5.2.2 は、紙媒体でも提供される雑誌を電子媒体で利用した場合に（取得日，URL またはデータベース名）の併記を求めています（規定28頁）。規定どおりに出力する場合は、Zotero の引用設定「論文の URL アドレスを参考文献目録に含む」（Include URLs of paper articles in references）を有効にしてください。

## 規定どおりに出力できない箇所（必ずお読みください）

Zotero のデータ構造上の制約から、次の3点は第3版の規定と異なる動作をします。この3点を了解したうえでお使いください。

### 1. 訳書・翻訳論文の文献リストは規定どおりには出力されません

第3版の規定では、訳書は「原典の書誌情報 .（訳者名訳，翻訳の出版年，『訳書のタイトル』出版社名．）」という2部構成で記します（規定25頁）。ただ、Zotero の1アイテムはタイトル・出版社・出版年を1組しか持てないため、この形式は自動では出力できません。本スタイルは訳書を、第2版までの記法に近い次の形で出力します。

> Merton Robert K.，1957=2024，『社会理論と社会構造』森東吾・森好夫・金沢実・中島竜太郎訳，みすず書房．

本文中の引用（規定の用語では「文献を示す割注」）のほうは（Merton 1957=2024）（Merton 1957=2024: 78）と規定どおりに出ます。翻訳された編書論文・章も同様に、「章題」編者名編『書名』訳者名訳，出版社，ページ．の形になります。**規定どおりの完全な2部形式が必要な場合は、文献リストの訳書・翻訳論文の項目だけ提出前に手で直してください。** 上の例を手で直すと、次の形になります（この行は本スタイルの自動出力ではありません）。

> Merton, Robert K., 1957, *Social Theory and Social Structure*, Glencoe, Ill.: The Free Press.（森東吾・森好夫・金沢実・中島竜太郎訳，2024，『社会理論と社会構造』みすず書房．）

1本の論文で数件程度のことが多いので、最終稿での修正を前提とした設計にしています。

なお、訳書の原著者名はアルファベットのフルネームで入力してください。規定9頁は本文中の引用を（原著者名 原書の出版年=訳書の出版年）の形と定めており、原著者名はアルファベットで示されます（本スタイルの出力では（Merton 1957=2024））。文献リストの欧文著者名は、規定19頁の印字例がフルネーム（本スタイルの例では Massey, Douglas S.）で、イニシャルのみも認められています。カタカナで入力すると本文中の引用もカタカナになり、規定の形から外れます。表記は1本の論文のなかで統一してください。

### 2. ウェブページの年は、日付が空のとき取得日の年になります

第3版3.8.1⑵（本文15頁）の規定では、ウェブページは出版年、最終更新年、取得日の年の順で年を採用します（印字例は4.5.3、本文29頁）。本スタイルはこれに対応して、「出版年月日」欄が空のウェブページ・ブログ記事では**「アクセス日時」の年**を年の位置に表示します。

> 吉野作造記念館，2026，「吉野作造とは？」，吉野作造記念館ホームページ，（2026年7月28日取得，https://www.yoshinosakuzou.info/blank-22）．

本文中の引用も（吉野作造記念館 2026）となります。ここから注意点がひとつ生じます。**原稿を確定した後に Zotero 上でアクセス日時を更新すると、本文中の（著者 年）と文献リストの年が変わってしまいます。** 仕上げのあとは該当アイテムのアクセス日時を変更しないでください。ウェブページ・ブログ以外の文献で出版年が不明な場合は、規定どおり n.d. と表示します。

### 3. 電子書籍も規定どおりには出力されません

規定（27頁）では、電子書籍は『タイトル』のあとに（紙媒体の刊行年，出版社）を併記しますが、訳書と同じ理由（1アイテムに書誌情報1組）で自動では出力できません。本スタイルは、通常の書誌情報に（取得日，URL）または（フォーマット）を添えた形で出力します。紙媒体の刊行情報まで必要な場合は手で補ってください。

## 自動で行われる処理（知っておくと安心です）

- **同姓の著者の区別**: 同じ姓の著者が複数あると、本文中の引用が自動で展開されます。和文は氏名すべて、英文は姓とイニシャルになります（規定8頁）。
- **同一著者・同一年の区別**: 2022a, 2022b のような年サフィックスが本文中の引用・文献リストの両方に自動で付きます（使い方ガイドの Kihara の例を参照）。年不明の文献どうしも n.d.a, n.d.b と区別されます。
- **著者不明のウェブページ**: 作成者欄が空でウェブサイト名が入っていれば、サイト名が著者名の位置に入ります（規定15頁）。
- **同一著者の文献の並び**: 単著 → 単独の編書 → 共著 → 共編書の順、同一カテゴリー内は出版年順に、原則として自動で並びます（規定18頁。例外は「このスタイルでできないこと」の配列の項を参照）。2件目以降の氏名は ―――― に置換されます。

## このスタイルでできないこと（手動対応が必要）

- **文献リストの配列**: 規定では日本人著者もローマ字順に並べますが、Zotero は漢字の読みを持たないため、和文文献は文字コード順になります。また、同一筆頭著者のもとに著者数の異なる共著と共編書が混在すると、カテゴリーの境界が規定順とずれることがあります（稀なケースです）。提出前に並び順を確認し、必要なら手で並べ替えてください。
- **新聞記事・商業雑誌**: 規定（14頁）では（『新聞名』発行年月日 朝刊）のように本文中の引用のみで、文献リストには載せません。この形式は自動出力できないため、本文中の引用を手動で記載してください。署名入り記事は文献リストに載せる規定ですが、本スタイルの新聞記事書式は未検証です。
- **カタカナ人名を含む共著**: 日本人著者とカタカナ表記の外国人著者の共著は、規定では著者名を全角スラッシュでつなぎますが、本スタイルはナカグロで出力します。
- **団体編者**: 規定では、和文の編書で編者が団体のときは「編」を記載しません（規定23頁）。欧文では ed. の省略は任意で、1本の論文のなかで統一します（規定20頁）。本スタイルは常に「編」を付けるので、団体が編者の項目は提出前に手で「編」を削ってください。
- **再録の書式**（初出誌と再録編著書の併記）には対応していません。
- **近刊・forthcoming** の表示には対応していません。
